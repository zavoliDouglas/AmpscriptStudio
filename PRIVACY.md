# Política de Privacidade — AMP Studio

**Última atualização:** 28 de agosto de 2026

## Resumo

O AMP Studio **não coleta, não armazena e não transmite** nenhum dado do
usuário. Todo o processamento acontece **localmente**, dentro do seu navegador.

## Que dados a extensão acessa

Para funcionar, o AMP Studio lê o trecho de código **AMPscript** que você
seleciona ou digita no editor do Content Builder do Salesforce Marketing Cloud
(nas páginas `*.marketingcloudapps.com` e `*.exacttarget.com`). Esse código é
processado apenas na memória do navegador, no seu computador, para gerar a
versão formatada e os diagnósticos.

Esse conteúdo **nunca sai do seu navegador**: não é enviado para nenhum
servidor, não é salvo em nenhum banco de dados e não é compartilhado com
terceiros.

## O que a extensão NÃO faz

- Não coleta dados pessoais.
- Não usa cookies nem rastreadores.
- Não utiliza serviços de analytics.
- Não envia dados para servidores externos.
- Não compartilha, vende ou transfere informações a terceiros.
- Não executa código remoto — todo o código é empacotado na própria extensão.

## Permissões utilizadas

- **sidePanel**: exibir a interface da extensão em um painel lateral.
- **Acesso ao host** (`*.marketingcloudapps.com`, `*.exacttarget.com`): ler o
  código AMPscript no editor do Content Builder para formatá-lo e validá-lo
  localmente.

Nenhuma dessas permissões é usada para coletar ou transmitir dados.

## Alterações nesta política

Caso esta política mude, a data de "última atualização" acima será revisada.
